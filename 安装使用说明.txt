DeadlockLingua 2.1.0 — 安装使用说明
========================================

一句话:把 Deadlock 里的外语聊天实时译成中文,译文直接显示在原消息下面。


一、安装(四步)
----------------------------------------

1) 解压
   把整个压缩包解到没有空格、没有中文的路径,例如 D:\DeadlockLingua

2) 【必做】给 Deadlock 加启动参数 -condebug
   Steam 库 → Deadlock 右键 → 属性 → 常规 → 启动选项,填:

       -condebug

   为什么必须加:游戏不带它就不会写 console.log,而那是我这边
   "把翻译请求送出去、把译文收回来"的唯一通路。少了它,mod 看起来
   就是"装了完全没反应"。
   (用包里的 StartDeadlock.bat 启动游戏会自动带上,可以跳过这步)

3) 把 mod 放进游戏
   压缩包里的 VPK 叫 pak01_dir.vpk,先改名成 pak22_dir.vpk 再复制到:

       <你的Steam库>\steamapps\common\Deadlock\game\citadel\addons\

   两条不能碰的红线:
     - 不要用裸的 pak01_dir.vpk 这个名字(pak01 是游戏本体的,会冲突)
     - 只能放 citadel\addons\,千万不要放到 citadel\ 下(会覆盖游戏资源)

   推荐用 Deadlock Mod Manager 导入。

4) 启动本地桥(二选一)
   - 双击 install-autostart.bat 装成开机自启(推荐)
   - 或双击 StartBridgeSilent.vbs 临时后台启动

然后重启 Deadlock。


二、怎么用
----------------------------------------

看译文:进对局就行。别人说外语,译文会直接出现在那条消息下面
        (浅蓝底、斜体)。译一条大约 2~6 秒,这是当前通道的物理上限,
        不是卡住了。

发消息:聊天框里打中文,按回车 —— 发送前会自动译成英文再发出去。

改设置:双击 ShowOverlay.bat 打开悬浮窗(不用先开游戏),点标题栏
        的"设置"。服务商、API Key、目标语言、显示模式、发送前翻译
        等都在这里改,改完点"保存"。


三、没反应怎么办(按顺序查)
----------------------------------------

1) 启动选项里有没有 -condebug          ← 绝大多数情况是这个
2) 桥在不在跑:浏览器打开
   http://127.0.0.1:8791/api/v1/health  能看到 JSON 就正常
   没起来就双击 StartBridgeSilent.vbs
3) 看 logs\bridge.log,找 BTIPC TRQ 或 BTIPC: r=.. seq=.. OK


四、常见问题
----------------------------------------

Q: 以前不是用悬浮窗看译文吗?
A: 那是 v2.0.x 的过渡方案(当时游戏移除了所有 HTTP 能力)。从 2.1.0 起
   译文回到游戏内,悬浮窗代码还在,想吃回头草可以在设置里切换。

Q: 输入 /tr 没反应?
A: 旧面板已随旧通道一起移除,/tr 现在会当成普通聊天文本发出去。
   设置请用悬浮窗里的"设置"页。

Q: 翻译失败会怎样?
A: 翻译服务商失败会回退显示原文;桥整个不在时约 3 秒放弃并跳过,
   不会在聊天里刷红色报错。


五、卸载
----------------------------------------

1) 删掉 addons 里的 pak22_dir.vpk(或你改的那个名字)
2) 双击 remove-autostart.bat 取消自启
3) 删掉整个 DeadlockLingua 目录


六、其他
----------------------------------------

- 聊天日志按对局写在 logs\chat\<matchId>.jsonl,赛后复盘用
- config\config.json 里有你的 API Key,不要发给别人、不要提交到 Git
